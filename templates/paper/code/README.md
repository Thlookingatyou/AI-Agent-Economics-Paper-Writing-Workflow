# Analysis code

Keep reusable transformations, model training and economic tests separate. Name entrypoints and their inputs/outputs. Record dependency locks, seeds and method sources. Use the private-data root rather than a machine-specific path. Save full estimates, samples where permitted and resumable checkpoints.

The workflow supplies organization and run recording, not a universal production estimator. Select validated methods for the research design. The synthetic demo is not a replacement for econometric packages.
