# Authoring source

Set `state.json.authoritative_manuscript` after the researcher identifies the active Word or LaTeX source. Do not assume that this directory, the newest timestamp or a file called main is authoritative. The researcher writes the main body and test descriptions by default.

For new LaTeX work, main.tex is a minimal article skeleton. Build with the available document tools/LaTeX engine, verify references and visually inspect output. For existing Word work, preserve the source and explicitly plan Word/LaTeX synchronization if needed. Bibliography style is configurable rather than a universal journal requirement.
