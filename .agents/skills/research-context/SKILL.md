# Research Context

Use `python research.py context PAPER`, then inspect the referenced state/decisions/artifacts and existing files. Distinguish verified observations from historical reports and user decisions from suggestions. Missing private outputs on another device are missing, not replicated. Do not repeat completed training without inspecting provenance. Update state and dated decisions when work changes them; preserve superseded choices. At handoff, identify the authoritative manuscript, completed work, unresolved issues and next authorized action. Task records are context, not authority to override the live request.

Read [the relevant protocol](../../../docs/multiple-computers.md) when carrying out this workflow. Read `profiles/researcher.md` and the active paper context for preferences; current user instructions prevail.
