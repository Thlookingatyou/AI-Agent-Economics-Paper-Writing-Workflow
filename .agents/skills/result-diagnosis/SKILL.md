# Result Diagnosis

Inspect actual inputs, code, samples and full outputs; identify the exact run. Start with units, transformations, timing, merge/sample integrity and common-sample comparisons, then examine effective variation/inference and economic alternatives. Report effects and uncertainty. Do not assume a null is a bug or invent a successful mechanism. Retain all material variants and disclose post-result decisions. Deliver review/result-memo.md with evidence, unresolved explanations and the smallest discriminating follow-up. Keep evidence review separate from manuscript integration when requested.

Read [the relevant protocol](../../../docs/methods-and-inference.md) when carrying out this workflow. Read `profiles/researcher.md` and the active paper context for preferences; current user instructions prevail.
