# Ai Trading Research

Read the AI-trading protocol and verified source version. Define economic primitives, information sets, timing, clearing, rewards and outcomes before agent architecture. Validate analytical/special-case benchmarks and simulator accounting. Match information/constraints across agent comparisons; separate training/evaluation seeds and report repeated-run uncertainty. Test strategic mechanisms against appropriate deviations/alternatives. Coordinated behavior is not by itself an identified collusive mechanism. Separate simulated implications from empirical prevalence and thematic AI exposure from actual algorithm use. Remain open to directions beyond any named paper.

Read [the relevant protocol](../../../docs/ai-trading.md) when carrying out this workflow. Read `profiles/researcher.md` and the active paper context for preferences; current user instructions prevail.
