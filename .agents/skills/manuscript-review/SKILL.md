# Manuscript Review

Establish the authoritative source and editing mode. For grammar-only, preserve scientific content and wording; list substantive concerns separately. Map claims to verified papers and actual run/artifact evidence. Check units, ranks, timing, sample, uncertainty and causal/mechanism language. Provide exact before/after wording and locations in review/edits.md. Draft or integrate only when requested; proceed without repeated permission inside authorized scope. Use direct prose and place necessary scope once where readers need it. Verify source/reference consistency and compile/visually inspect changed pages with available document tools; report checks not performed.

Read [the relevant protocol](../../../docs/manuscript-review.md) when carrying out this workflow. Read `profiles/researcher.md` and the active paper context for preferences; current user instructions prevail.
