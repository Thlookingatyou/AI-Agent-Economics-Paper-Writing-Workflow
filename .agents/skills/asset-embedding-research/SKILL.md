# Asset Embedding Research

Read the embedding protocol before choosing an architecture. Recover existing checkpoints and source methods. Define the economic object, objective, input coverage, timing, theme/score universe and independent validation. Separate representation selection from downstream economic tests; use matched samples and simple baselines. Audit full-sample pretraining, vocabulary/normalization/tuning leakage and partial holdings. Document equations-to-functions and deliberate adaptations. Plan resumable checkpoints and explain the method so the researcher can defend it. Do not train merely because a model was implemented; follow current execution scope.

Read [the relevant protocol](../../../docs/embeddings.md) when carrying out this workflow. Read `profiles/researcher.md` and the active paper context for preferences; current user instructions prevail.
