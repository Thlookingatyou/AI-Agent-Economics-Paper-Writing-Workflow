# Exhibits And Release

Use complete saved results and stable artifact IDs; do not hand-transcribe estimates when generated tables are possible. Follow the researcher's coefficient order and identify sample, effects, fit and inference. Map exhibit→run→script/config→full result→manuscript label. Keep review outputs separate as requested. For release, read docs/release.md and assemble a separate explicit allowlist; public code does not authorize distributing private data, weights or historical handoffs. Distinguish demonstration, validation, reconstruction and numerical reproduction. Compile and visually check requested deliverables using available tools.

Read [the relevant protocol](../../../docs/exhibits.md) when carrying out this workflow. Read `profiles/researcher.md` and the active paper context for preferences; current user instructions prevail.
