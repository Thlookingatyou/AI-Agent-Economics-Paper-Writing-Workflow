# Everyday requests

These examples are conveniences; ordinary language works. Replace PAPER with your paper slug.

**Resume:** “Read AGENTS.md and context for PAPER. Recover the latest artifacts and tell me what is verified, unresolved and authorized next.”

**Evaluate:** “Evaluate this asset-embedding idea. Verify the closest literature, distinguish method/measurement/application/identification contributions, audit feasible data, and recommend the smallest informative pilot. Do not train yet.”

**Suggest ideas:** “Suggest promising AI-trading questions grounded in the verified Goldstein papers. Separate simulation questions from empirical tests and rank them by contribution, feasibility and decisive evidence, not expected significance.”

**Inspect:** “Audit these exports, including disclosure completeness and availability timing. Preserve missing values. Return usable fields, gaps and a timeline before implementation.”

**Implement:** “Build the model from this version of the paper. Show the equation-to-code map and intentional adaptations. Code plus synthetic tests only; no full training.”

**Execute:** “Run the agreed protocol, retain all variants and nulls, save checkpoints, and deliver separate results. Keep the manuscript unchanged.”

**Diagnose:** “Explain this unexpected coefficient using actual sample/code/results. Check measurement, timing, common samples and inference before proposing an economic story.”

**Review writing:** “Check grammar minimally and list logic errors separately. Keep my wording where possible and give exact before/after text. Do not add interpretation.”

**Learn:** “Teach me this method so I can defend it: economic object, equation, training, worked example, baseline and failure modes. Relate it to my existing code.”

**Prepare mentor packet:** “Make a compact evidence packet with key tables, what we learned, unresolved alternatives and decisions needed. No paper integration.”
