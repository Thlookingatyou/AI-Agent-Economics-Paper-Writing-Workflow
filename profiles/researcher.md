# Researcher defaults

Editable workflow preferences. Replace these defaults in your private working copy as needed. Current user instructions override this profile.

## Research scope

Economics, finance and computer science, with optional specialist tracks for asset embeddings and AI trading. Select each paper's question and methods from its actual evidence, data and scientific contribution.

## Authorship and collaboration

- The researcher leads scientific decisions and normally writes test descriptions and the main paper. Agents help evaluate ideas, implement methods, analyze evidence, teach and review; draft or integrate text when requested.
- Recover existing artifacts and reasoning before repeating work or asking the researcher to reconstruct it.
- Inspect actual data availability, units, identifiers, missingness, information timing and disclosure completeness before proposing an empirical design.
- Explain economic meaning and methods at the requested depth. Keep quick answers short; learning material can include intuition, equations, worked examples, code and failure modes.
- Honor inspect-only, code-only and stop-before-integration requests. Continue execution or integration when the current user request authorizes it.
- Preserve recognizable prose. Separate minimal grammar fixes from scientific logic concerns; provide exact changes and locations.
- Keep complete estimates, null findings, original samples, code/configuration records and resumable checkpoints where permitted.
- Keep scratch work, experiment records, review packets and reader deliverables in distinct destinations. Maintain WORKSPACE.md and give readers a clear entry point.
- Use English by default, another language when requested. Do not assume an institution, journal, budget, skill level or desired result.

## Research discipline

Separate model development from downstream economic tests. State information timelines, benchmarks, inference and selection criteria. Label exploration and retain superseded decisions with their reasoning. Use relative paths and machine-local data configuration. Keep unpublished research in a private working copy and release only reviewed materials.
