# Paper workspaces

No paper workspaces, research notes, manuscripts, or empirical data are shipped in this public template.

Create a workspace in your private working copy with `python research.py new SLUG --title "Title" --track embeddings`. Available tracks are `embeddings`, `ai-trading`, and `general`. The command never overwrites an existing paper.

Commit permitted metadata, protocols, decisions, code, and author-controlled manuscript sources only to your private working repository. Raw/processed data and run outputs are excluded by default. Existing papers can be indexed without moving them; see [the adoption guide](../docs/legacy-adoption.md).
